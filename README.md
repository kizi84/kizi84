# Uzunov 90 — онлайн зоомагазин

Нов сайт и административен панел за зоомагазин **Uzunov 90** (УЗУНОВ 90 АНИМАЛПЕТС ООД) —
храни, лакомства и аксесоари за кучета и котки.

Изграден с Next.js 15 (App Router), TypeScript, Tailwind CSS 4 и Prisma.

---

## Какво включва

**Магазин**
- Начална страница с плавни анимации при скрол
- Каталог с филтри по марка, цена и наличност + подреждане и странициране
- Дървовидни категории (основни → подкategории)
- Продуктова страница с галерия, варианти (разфасовки), отзиви и свързани продукти
- Търсене на кирилица
- Количка (пази се в браузъра) и поръчка без регистрация
- Страници: доставка, за нас, контакти, общи условия, поверителност
- Двойни цени в евро и лева по фиксирания курс 1 € = 1,95583 лв.

**Административен панел** (`/admin`)
- Табло с оборот, нови поръчки, ниска наличност и най-продавани
- Поръчки — преглед, търсене, смяна на статус, вътрешни бележки
- Продукти — добавяне и редакция с drag & drop качване на снимки
- Категории, марки, отзиви (с одобрение), съобщения от формата за контакт
- Масов импорт на продукти от CSV/JSON

**Оптимизация**
- Статично генериране на продуктови и категорийни страници
- Автоматична обработка на снимките към WebP (макс. 1600 px)
- `sitemap.xml`, `robots.txt`, canonical адреси, Open Graph
- Структурирани данни (Schema.org): `PetStore`, `Product`, `BreadcrumbList`
- Достъпност: семантичен HTML, ARIA етикети, поддръжка на `prefers-reduced-motion`

## Стартиране

Нужен е Node.js 20 или по-нов.

```bash
npm install
cp .env.example .env      # и попълнете стойностите
npm run setup             # създава базата и зарежда началните данни
npm run dev               # http://localhost:3000
```

Админ панелът е на `http://localhost:3000/admin`
с данните от `ADMIN_EMAIL` / `ADMIN_PASSWORD` в `.env`.

> ⚠ **Сменете паролата и `AUTH_SECRET` преди публикуване.**
> `AUTH_SECRET` може да се генерира с `openssl rand -base64 32`.

### Променливи на средата

| Променлива | Описание |
| --- | --- |
| `DATABASE_URL` | Връзка към базата. По подразбиране SQLite файл. |
| `AUTH_SECRET` | Ключ за подписване на админ сесията (мин. 32 знака). |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | Първият администратор, създаван от `npm run db:seed`. |
| `NEXT_PUBLIC_SITE_URL` | Публичният адрес — ползва се за sitemap и canonical. |
| `UPLOAD_DIR` | Папка за качените снимки (по подразбиране `./uploads`). |

## Прехвърляне на продуктите от стария сайт

Каталогът от **uzunov90.com** се мигрира на две стъпки.

### 1. Сваляне

```bash
npm run import:legacy
```

Скриптът обхожда `browse.php?catid=…` и `product.php?id=…`, изважда име, цена,
описание и снимки и записва `products.json`. Полезни опции:

```bash
npm run import:legacy -- --max-products 50     # пробно сваляне
npm run import:legacy -- --base https://www.uzunov90.com
npm run import:legacy -- --out catalog.json --delay 500
```

Нищо не се записва в базата — прегледайте `products.json` първо.

> Стартирайте скрипта от машина, която има достъп до стария сайт.

### 2. Зареждане

Отворете `/admin/import`, качете файла, прегледайте таблицата и потвърдете.

Цените от стария сайт са в лева (`"currency": "BGN"`) и се превалутират
автоматично в евро. Категориите и марките се създават автоматично.
Импортът е **идемпотентен** — продуктите се разпознават по `legacyId`
и се обновяват, вместо да се дублират, така че може да се пуска многократно.

### Импорт от CSV

Същият екран приема и CSV. Задължителни колони са само `name` и `price`:

```csv
name,price,currency,category,parentCategory,brand,stock,images
Brit Care Adult Medium Lamb & Rice 12кг,82,BGN,Суха храна за кучета,Храна за кучета,Brit Care,5,https://.../a.jpg|https://.../b.jpg
```

Разпознават се и заглавия на кирилица (`име`, `цена`, `категория`, `марка`…).
Няколко снимки се разделят с `|`.

## Публикуване

### Собствен сървър (VPS)

```bash
npm ci
npm run build
npm run setup          # само първия път
npm start              # зад Nginx / Caddy
```

Държите процеса жив с `pm2`, `systemd` или Docker. Папките, които трябва да
оцелеят при обновяване, са базата (`prisma/dev.db`) и `uploads/`.

### Vercel и подобни

SQLite не е подходящ при хостинг без постоянен диск. Преминете към Postgres:

1. В `prisma/schema.prisma` сменете `provider = "sqlite"` на `"postgresql"`.
2. Задайте `DATABASE_URL` към базата.
3. `npx prisma db push && npm run db:seed`.

Качените снимки също се нуждаят от постоянно място — насочете `UPLOAD_DIR`
към монтиран диск или преминете към външно хранилище (S3, Cloudflare R2).

## Структура

```
prisma/
  schema.prisma          модел на данните
  seed.ts                начални категории, марки и продукти
scripts/
  import-legacy.ts       скрейпър за стария uzunov90.com
src/
  app/
    (shop)/              публичният магазин
    admin/               административен панел
    api/                 поръчки, отзиви, контакти, качване, импорт
    uploads/[...path]/   отдаване на качените снимки
  components/
    shop/                компоненти на магазина
    admin/               компоненти на админ панела
  lib/                   база, сесии, заявки, валидация, помощни функции
uploads/                 качените снимки (не се качва в git)
```

Снимките се пазят извън `public/`, защото Next.js отдава `public/` според
състоянието ѝ към момента на билда — файлове, записани след това, не биха се
виждали. Затова се отдават през `src/app/uploads/[...path]/route.ts`.

## Забележки по сигурността

- Админ сесията е подписан JWT в `httpOnly` бисквитка; всички `/admin` адреси
  минават през middleware.
- Паролите се хешират с bcrypt.
- Цените при поръчка се четат от базата, а не от заявката на клиента.
- Отзивите се публикуват само след одобрение от админ панела.
- Качените файлове се преобработват със `sharp` и се записват с генерирани имена.
